# 使用场景库

**目标：** 了解示例、宏和 AI 函数如何组合成针对真实场景的完整解决方案。

每个使用场景描述了具体情景、涉及的工具及其协同方式。跟随链接查看各组件示例，构建完整解决方案。

## 业务自动化

自动化文档繁重的工作流，减少人工操作和错误。

### 发票生成流水线

**场景：** 团队需要在不离开编辑器的情况下生成、计算和发送发票。

**解决方案：**

1. 使用[发票插件](../../samples/plugin-samples/invoices.md)拉取订单数据并填写模板。
2. 应用电子表格宏计算合计、税费和折扣。
3. 在发送前使用 PDF 编辑器宏设置验证规则。

**结果：** 可重复的一键发票生成工作流。

### 文档包创建器

**场景：** 销售团队需要从单一数据源一起生成合同、报价单和报告。

**解决方案：**

1. 使用[模板插件](../../samples/plugin-samples/templates.md)选择并填充文档模板。
2. 应用文档宏自动更新样式、页眉和页脚。
3. 将生成的文档包导出为 PDF。

## 教育工具

在编辑器内构建交互式语言学习和学习环境。

### 语言学习套件

**场景：** 教师希望直接在文档中创建语言练习、词汇表和阅读问题。

**解决方案：**

1. 结合[翻译器](../../samples/plugin-samples/translator.md)、[同义词词典](../../samples/plugin-samples/thesaurus.md)和[语音](../../samples/plugin-samples/speech.md)插件进行词汇学习。
2. 使用文档宏从选定段落生成阅读理解问题。
3. 使用自定义 AI 函数为不同水平的学生生成差异化练习。

## 内容创作

为写作者、编辑和设计师构建丰富的内容创作环境。

### AI 辅助创作环境

**场景：** 内容团队需要在一个地方拥有起草、图像编辑和丰富格式化工具。

**解决方案：**

1. 使用[图片编辑器插件](../../samples/plugin-samples/photo-editor.md)进行内联图像编辑。
2. 添加[符号表插件](../../samples/plugin-samples/symbol-table.md)用于特殊字符和排版。
3. 将 [AI 插件](../../samples/plugin-samples/ai.md)与自定义 AI 函数结合用于起草、改写和为长文本添加结构。

## 数据处理

直接在电子表格编辑器中构建数据管道和分析工作流。

### 自动报告生成器

**场景：** 分析师需要导入数据、运行计算并生成格式化的摘要报告。

**解决方案：**

1. 使用电子表格宏（排序、筛选、汇总）准备和清理数据。
2. 应用自定义 AI 函数解释公式结果并标记异常。
3. 使用[获取并粘贴 HTML 插件](../../samples/plugin-samples/get-and-paste-html.md)从外部系统拉取数据。
4. 使用文档宏从处理后的结果生成文档报告。

## 团队协作

让讨论和内容紧密结合，支持异步和远程团队。

### 以文档为中心的沟通中心

**场景：** 分布式团队希望在不切换到独立聊天工具的情况下讨论、注释和处理文档。

**解决方案：**

1. 使用[扩展评论](../../samples/plugin-samples/extended-comments.md)直接在文档中添加丰富的线程注释。
2. 集成 [Telegram 插件](../../samples/plugin-samples/telegram.md)将文档更新和评论发布到团队频道。
3. 使用宏和自定义 AI 函数从编辑后的文档内容生成会议记录、摘要和行动项列表。
