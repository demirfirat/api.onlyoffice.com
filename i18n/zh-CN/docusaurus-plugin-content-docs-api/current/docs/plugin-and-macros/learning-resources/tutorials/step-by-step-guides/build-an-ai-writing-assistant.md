# 构建 AI 写作助手

学习如何将 AI 插件基础与自定义 AI 函数相结合，创建特定领域的写作工具。

**您将构建的内容：** 一个插件面板，提供由自定义 AI 函数驱动的上下文感知写作建议、改写和摘要功能。
