# 构建 YouTube 插入器

学习如何使用 OLE 对象在 ONLYOFFICE 编辑器中嵌入和控制 YouTube 视频。

**您将构建的内容：** 一个打开自定义面板、接受 YouTube URL 并将视频作为嵌入文档的对象插入的插件。

**资源：**

1. 从 [YouTube 插件示例](../../../samples/plugin-samples/youtube.md)开始，探索完整代码。
2. 按照[插件开发教程](../../../get-started/get-started.md)从头搭建您自己的版本。
3. 参考[插件结构](../../../structure/configuration/configuration.md)文档，了解 `config.json`、`index.html` 和 `plugin.js` 如何配合工作。

**关键概念：** OLE 对象 · `Asc.plugin.executeMethod` · 外部 URL 处理
