# 构建表单验证器

学习如何使用宏自动验证 PDF 表单字段。

**您将构建的内容：** 一个检查表单字段是否符合验证规则、高亮无效条目并向用户报告问题的宏。

**资源：**

1. [更改验证规则](../../../samples/macro-samples/pdf-editor/change-validation-rules.md) — 以编程方式设置规则。
2. [限制字符数量](../../../samples/macro-samples/pdf-editor/limit-number-of-characters.md) — 强制输入长度限制。
3. [设置复选框提示文本](../../../samples/macro-samples/pdf-editor/set-checkbox-tip-text.md) — 为表单字段添加引导信息。

将这些模式组合成一个检查表单数据并高亮问题的单一宏。

**关键概念：** PDF 编辑器 API · 表单字段方法 · 宏组合
