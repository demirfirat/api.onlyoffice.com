# 宏示例

**目标：** 在无需编写完整插件的情况下自动化重复操作并添加文档逻辑。

从完整集合开始，或按您希望完成的任务类型筛选。

- **完整集合：** [浏览所有宏示例](../../../samples/macro-samples/macro-samples.md)

## 文本格式化

在文本文档中操作文本外观、样式和结构的示例。

参见宏集合中的**文档编辑器**示例：
- [文档宏](../../../samples/macro-samples/macro-samples.md#text-document-editor)

典型任务：

- 以编程方式应用段落和字符样式。
- 插入、替换或删除文本范围。
- 批量更改字体、颜色和对齐方式。

## 表格操作

在电子表格和文档内创建、修改和格式化表格的示例。

参见**电子表格编辑器**中关于范围、公式和布局的示例：
- [电子表格宏](../../../samples/macro-samples/macro-samples.md#spreadsheet-editor)

典型任务：

- 读写单元格值和范围。
- 应用条件格式。
- 排序、筛选和汇总数据。

## 数据处理

结合电子表格和文档宏导入、计算和报告数据。

典型任务：

- 从外部来源将数据导入电子表格。
- 运行计算并生成汇总行。
- 将结果导出为格式化文档或 PDF。

## 自动化脚本

编排多步操作、响应文档状态或将多个编辑器串联起来的宏。

典型任务：

- 对大型文档运行定期清理或格式化操作。
- 从模板文件生成、更新和分发报告。
- 将多个宏串联为一个自动化工作流。
