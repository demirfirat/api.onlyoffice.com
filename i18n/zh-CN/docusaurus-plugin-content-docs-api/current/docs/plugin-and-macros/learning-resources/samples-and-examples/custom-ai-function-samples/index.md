# 自定义 AI 函数示例

**目标：** 使用自定义函数以特定领域逻辑扩展 ONLYOFFICE AI 助手。

从完整集合开始，或按您希望 AI 执行的操作浏览。

- **完整集合：** [浏览所有自定义 AI 函数示例](../../../samples/custom-ai-functions-samples/custom-ai-functions-samples.md)

## 内容生成

使用 AI 函数在文档内起草、改写和摘要文本内容。

相关示例：
- [文档编辑器 AI 函数](../../../samples/custom-ai-functions-samples/custom-ai-functions-samples.md#text-document-editor)

典型任务：

- 根据简短提示生成初稿。
- 改写或重新表述选定段落。
- 将长文档摘要为要点列表。
- 按需翻译或本地化内容。

## 数据分析

使用 AI 函数解析电子表格数据、解释公式并挖掘洞察。

相关示例：
- [电子表格编辑器 AI 函数](../../../samples/custom-ai-functions-samples/custom-ai-functions-samples.md#spreadsheet-editor)

典型任务：

- 用简单语言解释复杂公式的作用。
- 突出数据范围中的异常或趋势。
- 从数值结果生成书面摘要。
- 建议改进数据结构或布局。

## 文档智能

使用 AI 函数检测结构、提取关键点，并丰富演示文稿和文档中的内容。

相关示例：
- [演示文稿编辑器 AI 函数](../../../samples/custom-ai-functions-samples/custom-ai-functions-samples.md#presentation-editor)

典型任务：

- 从文档中提取标题、关键术语或行动项。
