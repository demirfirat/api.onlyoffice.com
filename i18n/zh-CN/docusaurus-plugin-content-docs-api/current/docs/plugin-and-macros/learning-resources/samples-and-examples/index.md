# 示例与样本

**目标：** 通过示例学习。浏览可复制、修改和发布的可用代码。

选择您希望学习的代码类型：

## 插件示例

构建与 ONLYOFFICE 编辑器集成的丰富扩展。

- [浏览插件示例](./plugin-samples/index.md)

- **按类别：** 按解决的问题（集成、生产力、UI 增强、高级）查找示例
- **按复杂度：** 按难度（初级、中级、高级）查找示例
- **完整集合：** 在一处浏览所有插件示例

## 宏示例

在无需完整插件的情况下自动化文档操作并添加自定义逻辑。

- [浏览宏示例](./macro-samples/index.md)

- **文本格式化：** 操作文本外观、样式和结构
- **表格操作：** 创建、修改和格式化电子表格和文档表格
- **数据处理：** 导入、计算和导出文档数据

## 自定义 AI 函数示例

使用您自己的特定领域逻辑扩展 ONLYOFFICE AI 助手。

- [浏览自定义 AI 函数示例](./custom-ai-function-samples/index.md)

- **内容生成：** 使用 AI 起草、改写和摘要
- **数据分析：** 解析电子表格数据并解释公式
- **文档智能：** 从文档中提取结构和关键点
