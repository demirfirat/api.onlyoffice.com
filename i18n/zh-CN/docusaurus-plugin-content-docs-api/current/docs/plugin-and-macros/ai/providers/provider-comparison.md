# 提供商比较

ONLYOFFICE AI 插件支持任何兼容 OpenAI 的提供商。本页比较最常用的选项，以帮助您为您的使用场景选择合适的提供商。

## 比较表

| 提供商 | 定价 | 隐私 | 设置复杂度 | 最适合 |
|--------|------|------|-----------|--------|
| **OpenAI**（GPT-4o、GPT-4o mini） | 按令牌付费 | 数据发送至 OpenAI 服务器 | 低 | 通用任务，最佳质量 |
| **Anthropic Claude** | 按令牌付费 | 数据发送至 Anthropic 服务器 | 低 | 长文档，细致推理 |
| **DeepSeek** | 按令牌付费 | 数据发送至 DeepSeek 服务器 | 低 | 高性价比，强大的编码任务 |
| **Ollama**（自托管） | 免费 | 数据留在您的机器上 | 中 | 隐私敏感环境 |
| **自定义端点** | 不等 | 取决于部署方式 | 中–高 | 企业或专用模型 |

## 选择提供商

**选择 OpenAI 或 Anthropic**，如果您需要通用写作、摘要和分析任务的最高质量输出，并且对数据在外部服务器上处理没有顾虑。

**选择 DeepSeek**，如果成本效率是优先考虑的因素，且您的任务涉及技术或编码相关内容。

**选择 Ollama**，如果您在隐私敏感的环境中工作、处于受限网络中，或希望避免按请求计费。有关设置说明，请参阅[配置 Ollama 的 CORS](../configuration/configuring-ollama-with-cors.md)。

**选择自定义端点**，如果您的组织运行私有 AI 基础设施或需要通过标准提供商不可用的特定模型。有关实现详情，请参阅[添加自定义提供商](adding-custom-providers.md)。

## 在提供商内选择模型

大多数提供商提供不同功能和成本级别的多个模型。一般规则：

- 对格式化、短文改写和简单补全使用**较小/较快的模型**（如 GPT-4o mini）。
- 对复杂推理、长文档摘要和分析任务使用**较大/功能更强的模型**（如 GPT-4o、Claude Opus）。

您可以在 AI 插件设置中为不同的任务类型分配不同的模型（**设置 → 编辑 AI 模型**）。
