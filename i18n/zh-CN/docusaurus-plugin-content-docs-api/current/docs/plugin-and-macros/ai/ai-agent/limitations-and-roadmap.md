# 限制和路线图

AI 助手目前处于**测试版**阶段。本页记录已知的限制和计划改进。

## 当前限制

**添加自定义 AI 工具需要修改插件源代码。**
目前没有用于注册自定义工具的插件级 UI。开发者必须克隆 [AI 插件仓库](https://github.com/ONLYOFFICE/onlyoffice.github.io/tree/master/sdkjs-plugins/content/ai)，将工具添加到 helpers 文件夹，重新构建，并通过自定义商店链接部署。完整流程请参阅[创建自定义 AI 工具](../custom-ai-tools/creating-a-custom-ai-tool.md)。

**工具选择取决于 AI 模型的判断。**
助手依赖配置的模型根据用户的请求选择正确的工具。模糊或措辞不当的请求可能导致调用错误的工具。提供清晰、具体的指令可以提高准确性。

**对话历史基于会话。**
助手的对话历史不会在会话之间持久保存。关闭编辑器或按 `Ctrl + Alt + /` 会重置历史记录。

**并非所有编辑器功能都可通过助手访问。**
助手只能调用已注册的工具。没有相应工具的功能（例如，高级表格样式、复杂图表格式化）仍需手动应用。

**测试版可用性。**
AI 助手功能从 AI 插件 2.4.2 版本开始提供。某些行为可能会在未来版本中更改。

## 计划改进

AI 助手功能将持续发展。正在积极开发的领域包括：

- 用于注册和管理自定义工具的插件级接口，无需修改源代码。
- 跨编辑器会话的持久对话历史。
- 为所有编辑器类型扩展内置工具覆盖范围。
- 通过更好的提示工程和示例集提高工具选择准确性。

要请求功能或报告错误，请使用 [GitHub](https://github.com/ONLYOFFICE/onlyoffice.github.io/issues) 上的问题部分。
