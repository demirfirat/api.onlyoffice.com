# 运行您的第一个 AI 任务

[安装和配置](installing-ai-plugin.md) AI 插件后，您可以在任何支持的编辑器中开始使用。

## 使用 AI 选项卡

1. 在 ONLYOFFICE 中打开文档、电子表格或演示文稿。
2. 点击顶部工具栏中的**AI**选项卡。
3. 选择可用操作之一：
   - **设置** — 配置您的 AI 提供商、API 密钥和模型。
   - **聊天机器人** — 开始对话以提问、改写文本或头脑风暴。
   - **摘要生成** — 自动摘要输入的文本并插入结果。
   - **翻译** — 使用配置的 AI 服务翻译选定的文本。
4. 插件根据配置的 AI 模型进行响应。
5. 将响应插入文档或根据需要使用。

![AI 选项卡](/assets/images/plugins/ai-plugin.png#gh-light-mode-only)![AI 选项卡](/assets/images/plugins/ai-plugin.dark.png#gh-dark-mode-only)

## 使用上下文菜单

您也可以在选定的文本上使用 AI 插件：

1. 在编辑器中选择文本。
2. 右键点击并打开**AI**子菜单。
3. 选择选项之一：**语法和拼写**、**文本分析**或**聊天机器人**。

![AI 上下文菜单](/assets/images/plugins/ai-context-menu.png#gh-light-mode-only)![AI 上下文菜单](/assets/images/plugins/ai-context-menu.dark.png#gh-dark-mode-only)

## 使用 AI 助手

要获得更快的内联体验，请使用 AI 助手：

1. 在任何编辑器中按 `Ctrl + /`。
2. 用自然语言输入您的请求（例如，"总结这段文字"或"将这个标题加粗"）。
3. 按 `Enter`。

![AI 助手提示](/assets/images/plugins/ai-agent-prompt.png#gh-light-mode-only)![AI 助手提示](/assets/images/plugins/ai-agent-prompt.dark.png#gh-dark-mode-only)

助手会立即响应并支持多步骤对话——通过后续指令继续优化。

要重置对话历史，请按 `Ctrl + Alt + /`。要关闭助手，请按 `Esc`。

有关助手的更多详情，请参阅 [AI 助手](../ai-agent/what-is-ai-agent.md)。
