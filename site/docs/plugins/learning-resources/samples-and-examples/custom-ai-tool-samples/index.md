## Content generation

Use AI tools to draft, rewrite, and summarize text content inside documents.

Relevant samples:
- [Text document editor AI tools](/samples/?doctype=ai&text=ai+tools#text-document-editor)

Typical tasks:

- Generate first drafts from a short prompt.
- Rewrite or rephrase selected paragraphs.
- Summarize long documents into bullet points.
- Translate or localize content on demand.

## Data analysis

Use AI tools to interpret spreadsheet data, explain formulas, and surface insights.

Relevant samples:
- [Spreadsheet editor AI tools](/samples/?doctype=ai&text=ai+tools#spreadsheet-editor)

Typical tasks:

- Explain what a complex formula does in plain language.
- Highlight anomalies or trends in a data range.
- Generate a written summary from numeric results.
- Suggest improvements to data structure or layout.
